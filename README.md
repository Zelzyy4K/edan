# Steam Game Tools - Styled Prototype

Prototype browser-only sesuai style referensi yang diberikan: sidebar sederhana, topbar tipis, card gelap, border halus, spacing rapat, dan UI utility desktop.

Fitur tetap mengikuti spesifikasi Steam Game Tools:
- Dashboard
- Games + search/filter/favorite/details
- Bypass simulation
- Injection simulation
- Save & Restore simulation
- Fix tools
- Steam management simulation
- Activity Logs
- Settings + LocalStorage
- Global Search Ctrl+K
- Confirmation modal, progress, toast, empty state
- Responsive desktop layout

Tidak ada bypass DRM, anti-cheat evasion, credential theft, atau modifikasi Steam/game nyata.
Buka `index.html` langsung di browser.
